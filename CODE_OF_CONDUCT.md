# Code of Conduct

We want Pinpoint to be a welcoming project for everyone, whatever their experience, background or identity.

## Our standards

Do:

- Be respectful and patient, especially with newcomers.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.

Don't:

- Harass, insult or demean anyone, publicly or privately.
- Use sexualized language or imagery, or make unwelcome advances.
- Publish other people's private information without permission.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when representing the project elsewhere.

## Enforcement

Report unacceptable behavior by opening a private report through the repository's **Security** tab, or by contacting the maintainer through their GitHub profile. Reports are handled confidentially. Maintainers may remove comments or contributions and ban contributors who break these rules.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
